Seeing the ocean's small currents from space

A physics-informed neural network sharpens satellite sea-level maps to reconstruct submesoscale ocean currents (1–10 km), the small eddies and fronts that carry heat, carbon and nutrients between the surface and the deep ocean, but are blurred out of today's satellite products.

View the code on GitHub See the results

The problem

Satellites measure the height of the sea surface. Because of Earth's rotation, currents flow along the slopes of that surface (geostrophic balance), so a height map is also a map of currents. But gridded altimetry products blend many satellite passes and smooth everything smaller than about 100 km.

~100 km

The smallest features that standard gridded satellite sea-level maps resolve reliably in the Mediterranean.

1–10 km

Size of the submesoscale eddies and fronts that drive vertical exchange of heat, carbon and nutrients.

~5 km

Detail visible in satellite sea-surface temperature, which traces the same eddies. This is the extra information the network uses.

How it works

The network learns in a simulated ocean where the true fine-scale answer is known (an Observing System Simulation Experiment). It is then applied to real satellite data and checked against independent drifting buoys.

Truth

A high-resolution ocean reanalysis at 1/24° (~3.5 km) supplies sea level and temperature.

Degrade

Blur, sample and add noise so the fields look exactly like real satellite maps.

Learn

A residual CNN learns to restore the missing detail, using temperature as a guide.

Apply

Run on real Copernicus satellite sea level and temperature, 2022–2024.

Verify

Compare with drifting buoys and check the energy spectrum for artefacts.

Physics in the loss function

"Sharper" is not the same as "more accurate". The network is penalised for getting the physics wrong, not just the picture:

Sea level

Keeps the large-scale height field anchored.

Geostrophic currents

Scores the slopes, which are the currents themselves.

Rossby number ζ/f · new

Scores the spin of the flow, which is dominated by the smallest eddies.

Energy spectrum · new

Is the added detail real?

Two independent checks separate genuine ocean structure from artefacts that merely look sharp.

What's new

This builds on Ciani, Fanelli & Buongiorno Nardelli (Ocean Science 21, 2025), which reconstructed currents for the whole Mediterranean over 2008–2019.

New region & period

The Alboran–Balearic sub-basin in 2022–2024, overlapping the SWOT wide-swath satellite era. A Black Sea configuration is also included.

New loss terms

Rossby-number and energy-spectrum penalties added to the geostrophic constraint.

New diagnostic

A 10–50 km energy ratio that directly tests whether added detail is real or invented.

Reproducible

Every step is scripted, with 32 automated tests and a no-account demo that runs in minutes.

Run it yourself

The full pipeline runs on synthetic data in about three minutes on a laptop GPU, with no account needed.

git clone https://github.com/divyagoyal002/submesoscale.git
cd submesoscale
pip install -e ".[dev]"
submeso all -c configs/demo_synthetic.yaml
